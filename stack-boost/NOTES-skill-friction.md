# Skill / scaffold friction

- `scripts/new_project.py` runs `git init` in the new Project directory. Inside this repository that makes a nested repository, which `git add` would record as a submodule. The empty `.git` was removed by hand. Proposed fix: skip `git init` when the target is already inside a work tree (`git rev-parse --is-inside-work-tree`).
- The scaffold still lacks this repository's fixes: section reset (`model-sections`), `CARGO_TARGET_DIR=$PWD/target` in `validate.sh` and `install.sh`, and the transient-operating-point guard in `spice.py`. They were copied from four-stage-fuzz and green-overdrive.
- `harness/src/analog_harness/spice.py`, `render`: each section was cut at its first sample, so the SPICE source started at a nonzero value (filter ringing ahead of the section) and ngspice took it as a standing DC input when solving the operating point. Measured on this circuit at bass = mid = treble = 0: burst null -33.4 dB with the cut, -70.7 dB with a lead-in of silence. Fixed here with `lead_in(fs)` and an assert in `run_section`. Check that would have caught it: `test_spice_section_starts_from_silence` in `harness/tests/test_harness.py`. The other Projects' copies still have the cut. Whether it explains green-overdrive at level 0 is not tested.
- `harness/src/analog_harness/spice.py`, `downsample`: the delay is `(len(h) - 1) // 2 // OVERSAMPLE`. At 48 kHz the filter has 189 taps, so the true delay is 23.5 base samples and the output lags by half a sample. At 96 kHz (57 taps, 7 samples) it is exact. Seen in a harness test at 48 kHz; not fixed, because the Pack runs at 96 kHz. Check: assert `(len(h) - 1) // 2 % OVERSAMPLE == 0`.
- `harness/src/analog_harness/analysis.py`, `to_db`: amplitudes are clamped at an absolute floor. At a near-mute Setting the fundamental is so small that the clamp reads as a harmonic above -90 dBc (-62.3 dBc for a -40 dBFS tone at bass = mid = treble = 0), in both captures alike. The harmonics Check then compares two clamped numbers. It passes, but it measures nothing there. Check-less.
- The Solver leaves a standing output offset of about -1e-9 full scale (-7e-11 V) with no input: rounding in the companion current of the output capacitor, which holds 4.5 V. It is 52 dB below a -30 dBFS tone at the near-mute Setting. Not fixed.
