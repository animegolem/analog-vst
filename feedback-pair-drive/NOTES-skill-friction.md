# Skill and template friction

- **The joint Newton solve diverges when a junction is driven hard through a capacitor.** `dsp/src/circuit.rs`, `solve_joint` and the guess in `tick`. The template scales the whole Newton step by one factor so that no port moves more than 0.1 V. In this Circuit at Level 1 with a 5 V, 1 kHz input, Q5's base moves 0.7 V per circuit sample; the linear extrapolation put its base-emitter junction at 1.58 V forward, the step was dominated by a 60 V move of the collector, and the junction then moved 0.04 mV per iteration. The solve ran out of its 64 iterations and the output reached 1e21 V at sample 326. Fix in this Project: limit each junction's move as SPICE's `pnjlim` does, for the guess and for each step, and let the other ports take the full step. Check that would have caught it: a unit test that drives a capacitor-coupled transistor stage into cut-off and saturation and asserts the solve converged. This Project has one (`overdriven_sines_stay_bounded_and_converge`) and a `debug_assert!` on convergence. `solve_device` has the same single scale and was not changed; this Model does not use it.
- **A solve that does not converge is silent.** The template writes whatever the last iterate was into the state. Proposed: assert in debug builds, as here.
- **`scripts/new_project.py` creates a `.git` directory inside the new Project.** In a repository that holds many Projects this makes a nested repository. Removed by hand here. Proposed: a flag to skip it, or skip it when the target is already inside a work tree.
- **The harness fills the Netlist with `string.Template`**, so a dollar sign in a comment raises "Invalid placeholder". The schematic's own name for a pot gang contains one. Proposed: fill only the known placeholder names, or say so in the template Netlist's header.
- **`harness/src/analog_harness/cli.py`, `plain_controls`** runs `cargo run`, which builds into whatever `CARGO_TARGET_DIR` names. It is correct only because `validate.sh` exports the variable first. Calling the harness by hand without it reads another Project's binary. Proposed: call `target/release/render` directly, as `render_sections` does.
- **The SPICE runner's capture is band-limited at 4 times the pack rate.** For a hard-clipped 1 kHz sine at Level 1 the Model nulls against it to -49.6 dB; with the runner at 16 times the pack rate the same Model nulls to -55.9 dB, and doubling the Model's own rate changes nothing (-49.8 dB). So on square-edged signals part of the residual is the reference's sampling, not the Model. Check-less for now: no Check separates the two.
- **The first sample of a section that starts with a steep edge differs by up to 1 V** (Level 1, 5 V sine from zero phase: the output slews 20 V per pack sample). The two paths band-limit the onset with different filters. It is one sample; over a 0.2 s section the null is still -49.6 dB.
